# Homebrew tap for SimReel

[SimReel](https://github.com/SolankiYogesh/simreel) gives the iOS Simulator a working camera on Mac.

## Install

```sh
brew install --cask SolankiYogesh/tap/simreel
```

This installs **SimReel.app** into `/Applications` and puts the `simreel` command-line tool on your `PATH`.

Requirements: macOS 14 or later on Apple Silicon, with Xcode and the iOS Simulator installed.

## Update and uninstall

```sh
brew upgrade --cask simreel
brew uninstall --cask simreel
```

The cask follows the latest [GitHub release](https://github.com/SolankiYogesh/simreel/releases) and is updated automatically.
